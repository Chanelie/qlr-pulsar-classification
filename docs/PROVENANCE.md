# Data and software provenance

## Software

This repository implements the corrected random-number-generator scoping used
for the reported experimental grid. The supported workflow includes model
training, aggregation, calibration, bootstrap analysis, robustness analysis,
and figure generation.

The reference CSV files in `tables/` were generated by this corrected workflow.
They are provided for comparison with independently reproduced results.

## Dataset

The included `data/HTRU2.csv` file is the public HTRU2 dataset distributed by
the UCI Machine Learning Repository. Its source, DOI, licence, and SHA-256
checksum are recorded in `data/README.md`.

## Generated files

Binary model caches, figures, and run logs are generated locally and are not
tracked in the repository. Reproducing the results therefore requires running
the experiments before aggregation and figure generation.
