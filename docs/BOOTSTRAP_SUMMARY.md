# Paired bootstrap of the fixed test set

Generated by `scripts/bootstrap_test_set.py` (computation) and `scripts/bootstrap_summary.py` (this file). Full results: `tables/bootstrap_intervals.csv` — per-seed and pooled intervals for every (N, L, encoding) and every comparator.

**Method.** Test set = the main experiment's fixed split (3580 points, 328 pulsars). For each seed, B = 2000 class-stratified resamples with replacement; the same resample indices are applied to QLR and every comparator of that seed (paired), independent indices for different seeds. Metrics use the repository implementations (`average_precision_score`, `roc_auc_score`, `metrics_at_fpr`, `brier_score_loss`, 15-bin equal-mass `ece_from_probs`). Intervals are 2.5–97.5 % percentiles. **Pooled** = replicates of all listed seeds concatenated (e.g. 3 × 2000); the point value is the mean of the per-seed full-test-set values, so pooled intervals include seed-to-seed (training) variability as well as test-set sampling variability. Comparators include weighted and unweighted baselines, training-fold-calibrated baselines (Platt = `sigmoid`, isotonic), and QSVM.

Δ = QLR − comparator. Bold = the 95 % interval excludes 0; **Q** = QLR better, **C** = comparator better (for Brier and ECE, negative Δ = QLR better).
