# Results record

## Main-grid coverage

The corrected main grid contains:

- 135 QLR configurations: three encodings, three training-set sizes, five
  circuit depths, and three seeds;
- nine baseline/QSVM blocks: three training-set sizes and three seeds;
- 144 completed main-grid jobs in total.

The bundled CSV files under `tables/` are the summary tables produced from that
grid. Unless a table explicitly states otherwise, uncertainty is the
standard error over seeds 0, 1, and 2.

## Additional analyses

The repository also includes the supported code and summary tables for:

- unweighted classical-baseline comparisons;
- post-hoc calibration fitted using training data;
- a paired, class-stratified bootstrap of the fixed test set;
- a ten-seed sensitivity analysis for N = 200 and L = 3;
- a ten-split robustness analysis for N = 200 and L = 3.

## Important interpretation notes

- The QLR models use an unweighted binary cross-entropy objective.
- The main-grid classical baselines and QSVM use class weighting.
- A separate analysis evaluates unweighted classical baselines.
- Early stopping monitors training loss; no validation set was held out in the
  completed main grid.
- The simulator is analytic and uses no finite-shot or hardware-noise model.
- Runtime measurements were collected under varying machine load and should be
  interpreted as indicative rather than hardware benchmarks.
- Binary caches are not committed to this repository. They must be generated by
  running the experiments before aggregation or figure generation.
