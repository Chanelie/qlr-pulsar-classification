# HTRU2 dataset

`HTRU2.csv` is the HTRU2 pulsar-candidate dataset distributed by the UCI
Machine Learning Repository.

- Creator: Robert Lyon
- UCI dataset identifier: 372
- DOI: <https://doi.org/10.24432/C5DK6R>
- Source: <https://archive.ics.uci.edu/dataset/372/htru2>
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Instances: 17,898
- Features: 8 continuous features plus one binary target
- Local filename: `HTRU2.csv`
- SHA-256: `1B1BC22944D19D108794B9FA4DB58F01E4E439519FBB1D50FD3A72C5B996DC37`
